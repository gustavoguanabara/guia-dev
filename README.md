# GuIA do Programador Moderno 🚀

Portfólio imersivo e criativo com efeito Parallax multicamada e experiência 2.5D, desenvolvido com a metodologia Vibe Coding e engenharia orientada a agentes.

## 🌟 Tecnologias Utilizadas
- **HTML5 Semântico**
- **CSS3 Moderno** (Variáveis CSS, CSS Grid, Flexbox, Animações Cinemáticas)
- **JavaScript Vanilla (ES6+)** (Arquitetura modular orientada a eventos, física de parallax acelerada por hardware)
- **JSON Declarativo** para desacoplamento de catálogo de projetos
